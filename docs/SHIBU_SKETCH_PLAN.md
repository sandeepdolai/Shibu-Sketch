# Shibu-Sketch — Build Plan

A website recreation of the **Paper** journaling app experience (reference: user's videowatch recordings,
Paper by WeTransfer on iPad/desktop). Personal-use clone; all assets generated by us (no Paper assets).

**Repo:** https://github.com/sandeepdolai/Shibu-Sketch.git
**Codebase:** this Next.js 16 project. Route `/` renders the Shibu-Sketch app (single-page state machine).
The ACAN3D editor modules stay in the repo; its 3D engine primitives are **reused**:
`createPageGeometry` (pageGeom.ts), `applyPageTurnDeformation` (pageTurn.ts), `RoundedBoxGeometry`,
procedural textures (textures.ts), mulberry32.

---

## App Map (all states live under `/`)

```
shelf ──tap selected journal──▶ opening ──▶ open ──tap page──▶ drawing
  ▲        (blossom+lay flat)                 ◀──done── (2D editor overlay)
  └──── back ◀──── open          open ──back──▶ closing ──▶ shelf
shelf ──grid icon──▶ grid (journals lying flat)
"+" ──▶ new journal modal (cover designer)
```

## Views & Behaviors (pixel/animation spec)

### 1. Shelf (default)
- 3D scene, transparent canvas over CSS gradient `#8f8caa → #7f7c99`.
- Journals standing upright, covers facing camera, row centered; drag/swipe horizontal browse with
  cover sway; nearest-center journal = **selected** (lifts ~0.35u, soft shadow blob, sliders icon).
- Chrome: top-left Paper-style logo button `|||` + "Shibu Sketch" label; top-right count pill, search, menu;
  top-center `…`; center title (selected journal) + link icon + "N Pages"; bottom dock = 4 white circles
  (`…`, share, trash, `+`); right-edge page scrubber (only in open view).
- Click selected → `opening`. Click another → it slides to center & lifts.

### 2. Opening transition (~1.15s, choreographed)
1. Lift + slight back-tilt (0–20%)
2. **Blossom**: rotate around vertical spine axis while standing; pages fan out around spine (the
   "standing butterfly" seen in reference) (15–65%)
3. **Lay flat**: rotate X → open spread pose, camera dollies in + lowers angle; background crossfades to
   `#343b4d`; top bar swaps to journal mode (back-to-shelf + grid left; search + menu right) (60–100%)

### 3. Open journal
- Spread near-flat V (165–172°), camera ~25° above, pages cream `#faf8f4`, rounded corners.
- Page stacks fan on both sides (left = read, right = unread); stacks shrink/grow with flips.
- Flip forward: tap right half / → / scrubber. Flip back: tap left half / ←.
- Flip = real paper curl via `applyPageTurnDeformation` (C-curve), 420–480 ms, ease-out,
  dynamic shadow under flipping page, subtle book yaw toward flip, slight camera nudge.
- Right-edge scrubber pill: drag = scrub through spreads.
- Bottom dock: `…` (menu), share, trash, `+` (new page).

### 4. Drawing overlay (2D, full-screen)
- Enter: tap center of a page (or edit button) → page zooms flat; canvas overlay with paper background.
- Tools (bottom, Paper-style dock): pen, marker, highlighter, eraser, colors (palette popover),
  size slider, undo/redo, text tool, sticker tool (emoji/shapes), photo upload.
- Everything stored as **vector ops JSON** (strokes/texts/stickers/photos) → re-renderable to canvas
  → baked into the 3D page texture when exiting drawing.
- Done button (top-right) exits and re-enters 3D open view.

### 5. Grid view
- Journals lying flat (covers up) in responsive rows, slight isometric camera, same select/open flow.

### 6. New journal (+)
- Modal: title, cover style (solid color / gradient / pattern / emoji-collage generator), paper color
  → creates journal via API, appears on shelf with build-in animation.

### 7. Journal menu (…)
- Rename, duplicate, delete (confirm), export page as PNG, download journal JSON.

## Data Model (Prisma / SQLite)

```prisma
model Journal {
  id         String   @id @default(cuid())
  title      String
  coverStyle String   // JSON: {kind:'solid'|'pattern'|'photo', color, pattern, emoji, seed}
  paperColor String   @default("#faf8f4")
  order      Int      @default(0)
  pages      Page[]
  createdAt  DateTime @default(now())
  updatedAt  DateTime @updatedAt
}
model Page {
  id        String  @id @default(cuid())
  journalId String
  journal   Journal @relation(fields:[journalId], references:[id], onDelete: Cascade)
  index     Int
  content   String  @default("{}") // JSON: {strokes:[], texts:[], stickers:[], photos:[]}
  @@unique([journalId, index])
}
```

API (REST, relative): `/api/journals` GET+POST · `/api/journals/[id]` GET/PATCH/DELETE ·
`/api/journals/[id]/pages` GET+POST · `/api/pages/[id]` PUT · `/api/seed` POST (idempotent demo seed).

## 3D Engine (src/lib/sketch3d/)

- `journalObject.ts` — buildJournal(): standing journal group (front/back cover RoundedBox, page block,
  spine), cover texture from coverStyle (canvas-generated), page planes w/ rounded-corner geometry.
- `shelfScene.ts` — three.js renderer (alpha), shelf lighting, shadow plane, parallax camera rig
  (pointer-move / deviceorientation tilt).
- `openController.ts` — the 3-phase open/close choreography + camera moves (param t, eased segments).
- `flipController.ts` — page flip: lifts top-right page, curl deformation, shadow, stack re-fan, book yaw.
- `pageContentTexture.ts` — page content JSON → offscreen canvas → THREE.CanvasTexture (crisp 2x DPR).
- `demoContent.ts` — generated demo journals (Movies-style collage w/ watercolor + Caveat text + emoji
  stickers, Trips boarding passes, Sketchbook doodles) drawn procedurally.

## Milestones

- **S2-a** (main): 3D engine + scene + shelf + open/close + flip (the core).
- **S2-b** (subagent): Prisma schema + all API routes + demo seed (no UI).
- **S2-c** (subagent): DrawingOverlay editor + vector-ops renderer + tools.
- **S2-d** (subagent): chrome components (top bars, dock, scrubber, modal, grid view, toasts).
- **S3** (main): integration, mobile/responsive pass, E2E via agent-browser, perf (instancing if needed),
  README + push to Shibu-Sketch.

## Non-goals (explicitly excluded by user's spec)
- No AI chat / prompt-to-3D UI. No video "Mix" pages. No accounts/auth. No real Paper assets/photos.
